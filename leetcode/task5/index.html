Следующая лексикографическая перестановка

Описание задачи

Дан массив целых чисел nums, представляющий перестановку чисел. Необходимо изменить nums на месте, чтобы он стал следующей лексикографической перестановкой. Если такой перестановки не существует (массив находится в убывающем порядке), необходимо преобразовать массив в наименьшую возможную перестановку (отсортированный по возрастанию массив).

Нельзя использовать дополнительную память — преобразование должно быть in-place.

Примеры

Пример 1

Вход: nums = [1, 2, 3]

Выход: [1, 3, 2]

Пример 2

Вход: nums = [3, 2, 1]

Выход: [1, 2, 3]

Пример 3

Вход: nums = [1, 1, 5]

Выход: [1, 5, 1]

Ограничения

  • 1 ≤ nums.length ≤ 100
  • 0 ≤ nums[i] ≤ 100

Объяснение

  • Находим первое место (с конца), где текущий элемент меньше следующего. Это указывает на точку “перелома”.
  • Ищем наименьший элемент справа от этой точки, который больше найденного, и меняем их местами.
  • Переворачиваем хвостовую часть массива после точки перелома, чтобы получить минимально возможную последовательность справа.

Сложность

  • Временная сложность: O(n) — один проход для нахождения точки перелома, один проход для поиска элемента и один для разворота.
