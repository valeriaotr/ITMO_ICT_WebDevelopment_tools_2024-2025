Кратчайший палиндром c добавлением в начало (Shortest Palindrome)

Описание задачи

Дана строка s. Разрешено добавлять символы только в начало, чтобы получить палиндром. Нужно вернуть самый короткий возможный палиндром.

Примеры

Пример 1

Вход:

s = "aacecaaa"

Выход:

"aaacecaaa"

Ограничения

  • 0 <= s.length <= 5 * 104
  • s состоит только из английских букв нижнего регистра

Объяснение решения

  • Ищем наибольший палиндромный префикс строки s.
  • Строим строку t = s + '#' + reverse(s) и считаем для неё префикс-функцию (LPS, как в KMP).
  • Последнее значение LPS — длина наибольшего префикса s, который совпадает с суффиксом reverse(s), то есть длина палиндромного префикса.
  • Недостающий хвост берём как reverse(s)[:len(s)-longest] и добавляем спереди к s.

Сложность

  • Время: O(n)
  • Память: O(n)
