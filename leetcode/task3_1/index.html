Длина кратчайшей цепочки слов (Word Ladder I)

Описание задачи

Даны beginWord, endWord и список слов wordList. Нужно вернуть количество слов в кратчайшей последовательности преобразований из beginWord в endWord, где на каждом шаге меняется ровно одна буква и каждое промежуточное слово содержится в wordList. Если пути нет — вернуть 0.

Примеры

Пример 1

Вход:

beginWord = "hit"
endWord   = "cog"
wordList  = ["hot","dot","dog","lot","log","cog"]

Выход:

5

Пояснение:

Кратчайший путь hit → hot → dot → dog → cog содержит 5 слов.

Пример 2

Вход:

beginWord = "hit"
endWord   = "cog"
wordList  = ["hot","dot","dog","lot","log"]

Выход:

0

Пояснение:

cog отсутствует в словаре — пути нет.

Ограничения

  • 1 ≤ len(beginWord) ≤ 10
  • len(endWord) = len(beginWord)
  • 1 ≤ len(wordList) ≤ 5000
  • Все слова — строчные латинские буквы, уникальны
  • beginWord ≠ endWord

Объяснение решения

  • Используем двунаправленный BFS: одновременно расширяем фронты поиска из beginWord и endWord.
  • На каждом шаге расширяем меньший фронт (оптимизация), генерируя все слова, отличающиеся на 1 букву.
  • Если фронты встречаются — найден кратчайший путь; возвращаем его длину (step + 1).
  • Если endWord не в словаре — сразу 0.

Сложность

  • Время: O(N · L · 26) ≈ O(N·L), где
  • N — число слов в словаре, L — длина слова. Двунаправленный BFS обычно в разы быстрее одностороннего.
  • Память: O(N) для множеств и посещённых слов.
