Поиск всех кратчайших цепочек слов (Word Ladder II)

Описание задачи

Даны два слова beginWord и endWord, а также список слов wordList. Необходимо найти все кратчайшие последовательности преобразований из beginWord в endWord, где: - Каждое преобразование меняет ровно одну букву. - Каждое промежуточное слово должно находиться в wordList. - beginWord может не быть в wordList. - Последнее слово в цепочке всегда равно endWord.

Если преобразование невозможно, вернуть пустой список.

Примеры

Пример 1

Вход:

beginWord = "hit"
endWord = "cog"
wordList = ["hot","dot","dog","lot","log","cog"]

Выход:

[["hit","hot","dot","dog","cog"],
 ["hit","hot","lot","log","cog"]]

Пояснение:

Существует 2 кратчайших пути из hit в cog: - hit → hot → dot → dog → cog - hit → hot → lot → log → cog

Пример 2

Вход:

beginWord = "hit"
endWord = "cog"
wordList = ["hot","dot","dog","lot","log"]

Выход:

[]

Пояснение:

Слово "cog" отсутствует в списке, поэтому преобразование невозможно.

Ограничения

  • 1 ≤ len(beginWord) ≤ 5
  • len(endWord) == len(beginWord)
  • 1 ≤ len(wordList) ≤ 500
  • Все слова состоят из строчных латинских букв.
  • beginWord ≠ endWord
  • Все слова в wordList уникальны.
  • Суммарное количество всех кратчайших путей не превышает 10⁵.

Объяснение решения

  • Используется поиск в ширину (BFS) для построения графа переходов между словами.
  • В процессе строится словарь parents, где для каждого слова хранятся все возможные “родители”.
  • Когда найден endWord, дальнейшие уровни не рассматриваются (гарантия кратчайшего пути).
  • После BFS выполняется обратный проход (backtracking) от endWord к beginWord, чтобы восстановить все возможные пути.

Сложность

  • Временная сложность: O(N * L²), где
    • N — количество слов в словаре,
    • L — длина слова.
  • Пространственная сложность: O(N * L) для хранения графа и родительских связей.
