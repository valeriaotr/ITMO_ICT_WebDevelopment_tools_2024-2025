Обратный порядок цифр в 32-битном знаковом числе

Описание задачи

Реализуйте функцию, которая получает 32-битное знаковое целое число x и возвращает его значение с обратным порядком цифр.

Если при этом результат выходит за границы диапазона 32-битного знакового целого числа [-2³¹, 2³¹ - 1], функция должна вернуть 0.

Также предполагается, что в окружении нельзя использовать 64-битные целые числа.

⸻

Примеры

Пример 1

Вход: - x = 123

Выход: - 321

Пример 2

Вход: - x = -123

Выход: - -321

Пример 3

Вход: - x = 120

Выход: - 21

Ограничения

•   −2³¹ ≤ x ≤ 2³¹ − 1
•   Нельзя использовать переменные, превышающие 32-битное целое число

Объяснение реализации

1.  Определяем знак числа и работаем с его абсолютным значением.
2.  Преобразуем число в строку, переворачиваем её и снова преобразуем в число.
3.  Проверяем, находится ли результат в допустимом диапазоне 32-битного числа.
4.  Если выходит за границы — возвращаем 0, иначе — результат с учетом знака.

Сложность

•   Временная сложность: O(n), где n — количество цифр в числе.
