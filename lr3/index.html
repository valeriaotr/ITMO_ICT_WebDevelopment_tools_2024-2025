Лабораторная работа №3

Описание возможностей

Пользователь может отправить список URL-адресов через REST API и получить структурированные данные: название мероприятия, краткое описание и технический статус запроса.

Доступно два режима работы: - Синхронный режим — быстрый парсинг в рамках HTTP-запроса. - Асинхронный режим — постановка задачи в очередь, обработка в фоне, получение результата по task_id.

Архитектура

  • API-сервис (FastAPI) — точка входа для клиентов. Предоставляет эндпоинты /parse/http, /parse/async, /tasks/{id}.
  • Parser-сервис — модуль, который напрямую обрабатывает HTML-страницы: скачивает контент и извлекает из него заголовок и описание.
  • Worker (Celery) — пул рабочих процессов, которые выполняют асинхронные задачи.
  • Redis — брокер сообщений и хранилище статусов задач Celery.
  • PostgreSQL — база данных для хранения результатов парсинга.

Парсинг

Синхронный парсинг

POST /parse/http

Запрос:

{
  "urls": [
    "https://hackathons.pro/tpost/jmg3d12jj1-hakaton-vkrum-ot-rtu-mirea-vk-i-rustore"
  ]
}

Ответ:

{
  "message": "Parsing completed",
  "count": 1,
  "elapsed_sec": 0.54,
  "items": [
    {
      "url": "https://hackathons.pro/tpost/jmg3d12jj1-hakaton-vkrum-ot-rtu-mirea-vk-i-rustore",
      "status": 200,
      "title": "Хакатон VKRuM от РТУ МИРЭА, VK и Rustore",
      "description": "Формат: онлайн. Призовой фонд: 300.000 ₽"
    }
  ]
}

Асинхронный парсинг

POST /parse/async

Запрос:

{
  "urls": [
    "https://hackathons.pro/tpost/7i620ksj51-vserossiiskii-hakaton-fits-2024"
  ]
}

Ответ:

{
  "task_id": "caf9209f-9ac5-4fc5-9900-18e1c09c9304",
  "status": "PENDING"
}

Проверка статуса задачи

GET /tasks/{task_id}

Запрос:

curl http://localhost:8010/tasks/caf9209f-9ac5-4fc5-9900-18e1c09c9304

Ответ:

{
  "task_id": "caf9209f-9ac5-4fc5-9900-18e1c09c9304",
  "state": "SUCCESS",
  "result": {
    "count": 1,
    "items": [...]
  }
}
